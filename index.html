Klaim SQK — eksekusi dari wallet kamu

Ini bagian yang membedakan tool ini dari dashboard baca-saja: tombol klaim membangun transaksi claim() ke kontrak staking dan mengirimnya lewat wallet kamu sendiri. Tool ini tidak pernah memegang kunci dan tidak bisa klaim atas nama siapa pun.

Belum connect. Connect wallet yang memegang Squeek yang di-stake (untuk Leo: wallet ketiga 0xBfd0…1338).

Syarat klaim: jaringan Sepolia (11155111) + saldo Sepolia ETH untuk gas + claimable > 0.
Ingat: klaim selalu dari wallet pemilik stake. Kalau alamat yang connect bukan depositor #4844, claimable-nya akan terbaca 0 dan transaksi tidak ada gunanya — cek dulu di bagian 01.

    Pastikan chain-nya Ethereum Sepolia (11155111) dan alamatnya wallet ketiga 0xBfd0Fe82C81d2319D7a536B4126f7353Be2b1338.

  2. Pastikan ada Sepolia ETH

    Gas klaim dibayar pakai Sepolia ETH (testnet). Tanpa itu transaksi gagal sebelum jalan.

  3. Panggil claim() di kontrak staking

    Kontrak: 0x50fd…11ca — bisa dari tombol di tool ini, atau lewat Etherscan Sepolia → Contract → Write → claim.

  4. Verifikasi saldo bertambah

    Setelah sukses, saldo SQK naik dari 413,55 → ±463,21 SQK dan claimable kembali 0. Cek ulang di bagian 01.

Kenapa claimable berhenti di 49,66 SQK?

Karena stream reward-nya sudah selesai: remaining = 0 dan streamRate = 0 on-chain. Seluruh dana stream (7.753.344,18 SQK) sudah terakru ke para staker — sebagian sudah dibayar, sebagian di-compound, sisanya menunggu diklaim seperti 49,66 SQK punya Leo. Angka ini final dan tidak akan bertambah sampai stream baru didanai.

Apakah tool ini bisa stake / unstake NFT?

Stake dan unstake NFT dilakukan di situs resmi Squeekchain (transaksi deposit/withdraw ke kontrak staking yang sama). Tool ini fokus ke manajemennya: memverifikasi status stake wallet mana pun (depositor()), membaca power & claimable secara live, merencanakan power/merge, dan mengeksekusi klaim. Untuk #4844, statusnya sudah terverifikasi staked sejak 6 Nov 2026.

Tool ini dibuat untuk apa?

Tool ini adalah proyek builder untuk badge “The Buildooooor” di Squeekchain Genesis — mengisi celah yang belum ada di board Genesis: tool manajemen staking yang benar-benar mengeksekusi (klaim), bukan planner/dashboard baca-saja. Dibangun oleh LordSagai (invite K5B4J8JA).
